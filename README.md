# CropGuard

CropGuard es un proyecto de aplicación móvil desarrollado con Flutter, orientado al apoyo en el diagnóstico de cultivos a partir de imágenes de hojas.

## Objetivo

Proporcionar una interfaz para consultar cultivos, revisar el historial de diagnósticos y acceder a una funcionalidad de análisis de imágenes.

## Estructura del repositorio

- `cropguard/`: contiene el proyecto Flutter, el código fuente, las dependencias y los recursos gráficos.
- `cropguard/README.md`: contiene la documentación técnica de la aplicación móvil.
- `LICENSE`: contiene la licencia del repositorio.

## Tecnologías principales

- Flutter y Dart.
- Flutter BLoC para la gestión del estado.
- GoRouter para la navegación.
- Dio para las solicitudes HTTP.

## Ejecución

Consulta las instrucciones de instalación y ejecución en [`cropguard/README.md`](cropguard/README.md).

## Estado del proyecto

La documentación describe la estructura del código disponible. El funcionamiento completo de las funcionalidades depende de su implementación y de la integración con el backend.
