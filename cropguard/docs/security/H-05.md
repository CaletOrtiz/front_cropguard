## Cambios implementados

1. El manifiesto principal declara `usesCleartextTraffic="false"` y referencia `@xml/network_security_config`; la política principal usa `cleartextTrafficPermitted="false"`. Profile hereda esa política.
2. Solo debug reemplaza el atributo a `true` y superpone el recurso con `cleartextTrafficPermitted="true"`. Conserva USB con `adb reverse`, emulador y LAN.
3. `ApiEndpoints.defaultBaseUrl` lee `FASTAPI_BASE_URL` por `--dart-define`. Release y profile fallan de forma cerrada si falta la URL o no es HTTPS. No se inventa un dominio de producción.
4. `ApiTransportPolicy` valida las URL de inicialización y actualización, y se instala antes del interceptor que añade el JWT. Comprueba también la URL final de cada petición; fuera de debug bloquea HTTP absoluto y cambios directos de `Dio.options.baseUrl`. No depende de `assert`.
5. Se desactivan redirecciones automáticas fuera de debug para impedir que el adaptador siga un destino HTTP sin pasar por el interceptor. Los errores de validación no reproducen la URL aportada. No se alteran las comprobaciones de certificados TLS.

Estas medidas forman una corrección del hallazgo H-05.
